# موقع واصل الثابت (Wasel website)

موقع تنزيل ثابت بدون أي خطوة بناء لتشغيله، بتصميم مستوحى من GNOME / Adwaita، ويدعم العربية (RTL) والإنجليزية كاملتين. كل قسم له صفحة HTML مستقلة، مع حركات خفيفة تعمل بسلاسة حتى على الاتصالات البطيئة.

## الصفحات

| الصفحة | المحتوى |
| --- | --- |
| `index.html` | الرئيسية: زرا التحميل المستقر والتجريبي، لقطة التطبيق، أهم المزايا وآخر إصدار. |
| `download.html` | خيارات التحميل المباشرة وروابط كل المنصات. |
| `features.html` | المزايا الثمانية وشريط متحرك لشعارات المواقع المدعومة. |
| `platforms.html` | ويندوز، لينكس، أندرويد، وماك (من المصدر). |
| `files.html` | كل الملفات مع فلترة وبحث ونسخ الروابط وبصمات SHA-256. |
| `releases.html` | سجل الإصدارات السابقة. |
| `faq.html` | الأسئلة الشائعة. |
| `developer.html` | المطوّر زروقي احمد معاذ وحساباته بالصور. |

## الملفات المشتركة

| الملف | الوصف |
| --- | --- |
| `styles.css` | التصميم، الثيمات، الحركات، والتجاوب مع كل الشاشات. |
| `app.js` | الترجمة، الثيمات، عرض الملفات والإصدارات، النسخ، جلب النجوم، وحركة العدّاد. |
| `build-pages.js` | مولّد اختياري يعيد إنشاء كل صفحات HTML بشكل متسق: `node build-pages.js`. لا حاجة له للنشر. |
| `assets/fonts/cairo-subset.woff2` | خط Cairo محلي مخفّض (~42 KB) يحوي الحروف المستخدمة في الموقع فقط، بلا طلب إلى Google Fonts. |
| `assets/favicon.svg` | شعار التطبيق من `build/icon-master.svg`. |
| `assets/app-screenshot.webp` / `.png` | لقطة حقيقية من التطبيق (WebP خفيف مع PNG بديل). المصدر: `sceenshot/app.png`. |
| `assets/sites/` | شعارات حقيقية للمواقع المدعومة (Simple Icons، محفوظة محليًا بألوان العلامات). |
| `assets/accounts/` | صور حسابات المطوّر من مجلد `my accounts pfp`. |

## التشغيل

افتح `index.html` مباشرة في المتصفح، أو شغّل خادمًا محليًا:

```bash
cd website
python -m http.server 8000
# ثم افتح http://localhost:8000
```

للنشر على GitHub Pages: اختر مجلد `website` كمصدر للنشر من إعدادات المستودع ← Pages. لا توجد خطوة بناء مطلوبة؛ انسخ المجلد كما هو.

## الحركات والتجربة

- ظهور تدريجي للعناصر عند التمرير، عدّاد متحرك للإحصائيات، أضواء خلفية هادئة، شريط شعارات متحرك بلا توقف، وتوهّج خفيف لأزرار التحميل.
- احترام إعداد `prefers-reduced-motion`: تُوقف الحركات تلقائيًا لمن يفضّل ذلك.
- اللغة والثيم محفوظان في `localStorage` وينتقلان معك بين الصفحات.
- عنوان كل صفحة يتغيّر مع اللغة، والقائمة النشطة تُحدَّد تلقائيًا.

## الأداء على إنترنت بطيء

الوزن الأولي للرئيسية حوالي **163 KB** (HTML + CSS + JS + الخط + لقطة WebP + الشعار)، أي أقل من ثانية على اتصال 200 KB/ث، وينخفض كثيرًا مع ضغط gzip على GitHub Pages. لقطة PNG بديلة تُحمَّل فقط إن كان المتصفح لا يدعم WebP. صور الحسابات والشعارات تُحمَّل عند ظهورها (`loading="lazy"`).

## الأقسام والمحتوى

- زرّان مباشران أعلى الصفحة: أحدث إصدار مستقر (Windows x64) والإصدار التجريبي (Android APK).
- قسم المطوّر «زروقي احمد معاذ» مع حساباته: إنستغرام ×2، GitHub، تيك توك، ديسكورد (نسخ الاسم)، و`@mouad.kennedy.2001@gmail.com` عبر زر بريد مباشر.
- شعارات مواقع حقيقية بدل النصوص، ولقطة تطبيق فعلية أخف من الواجهة المصوّرة بـ CSS.
- عدد النجوم يُجلب لحظيًا من GitHub API، مع قيمة احتياطية تعمل دون اتصال.

## تحديث بيانات الإصدارات

البيانات مضمّنة في أعلى `app.js` داخل `RELEASES` (الوسم، التاريخ، الأصول، الأحجام، وبصمات SHA-256) ومأخوذة من:

- `https://api.github.com/repos/mouadkennedy2001/Honk-video-downloader`
- `https://api.github.com/repos/mouadkennedy2001/Honk-video-downloader/releases?per_page=20`

عند نشر إصدار جديد، أضف عنصرًا جديدًا إلى المصفوفة، وحدّث روابط `v2.0.0` في `build-pages.js` ثم شغّل `node build-pages.js` لتحديث كل الصفحات دفعة واحدة.
