# Honk Downloader

تطبيق سطح مكتب لتحميل الفيديو والصوت من آلاف المواقع، مع متصفح مدمج وتصميم مستوحى من دليل `DESIGN.md` (خلفية Honk Blue، لمسات Signal Yellow، وألواح بيضاء بحواف 16px).

بُني التطبيق باستخدام **Electron + Node.js**، ويعتمد في التحميل على **yt-dlp** و**FFmpeg**.

---

## المزايا

- تحميل الفيديو بأفضل جودة من يوتيوب، إنستغرام، فيسبوك، تيك توك، X، فيميو، SoundCloud، وغيرها من المواقع التي يدعمها yt-dlp (أكثر من ألف موقع).
- دعم الروابط المباشرة لأي ملف فيديو أو صوت، والمواقع التي تعرض `mp4` أو `m3u8`.
- دمج الفيديو والصوت تلقائيًا عبر FFmpeg، واستخراج الصوت بصيغ MP3 وM4A وOpus وWAV وFLAC.
- اختيار الجودة (best / 2160p / 1440p / 1080p / 720p / 480p / 360p).
- دعم قوائم التشغيل: تحميل العنصر الحالي أو القائمة كاملة.
- تحميل الترجمات ودمجها، ودمج البيانات والغلاف في الملف النهائي عبر FFmpeg.
- متصفح مدمج لتصفّح أي موقع ثم تحميل الصفحة الحالية بضغطة زر.
- تحميل رابط محدد من داخل المتصفح عبر قائمة النقر الأيمن.
- اختيار مصدر الكوكيز: المتصفح المدمج أو Chrome أو Firefox أو Brave أو Edge أو Opera أو Vivaldi أو Safari.
- تثبيت إضافات Chrome في المتصفح المدمج من مجلد أو ملف `.crx` أو `.zip`.
- إضافة **Honk Media Grabber** مدمجة لاكتشاف روابط الفيديو والصوت، مع نافذة منبثقة وزر «إرسال إلى التطبيق».
- جسر محلي آمن (`127.0.0.1`) لاستقبال الروابط من الإضافة أثناء تشغيل التطبيق.
- قائمة تحميلات متقدمة مع نسبة التقدّم والسرعة والوقت المتبقي وإمكانية الإلغاء، وحد أقصى للتحميلات المتزامنة.
- تثبيت أو تحديث yt-dlp وFFmpeg بضغطة زر من الإعدادات، دون الحاجة إلى الطرفية.
- ثلاث سمات: فاتحة وداكنة وحسب النظام، مع واجهة عربية RTL جديدة.

## المتطلبات

| الأداة | الحد الأدنى | الغرض |
|---|---|---|
| Node.js | 18 أو أحدث | تشغيل Electron |
| npm | 9 أو أحدث | تثبيت الحزم |
| yt-dlp | أي إصدار حديث | استخراج روابط الفيديو من المواقع |
| FFmpeg | أي إصدار حديث | دمج الفيديو والصوت وتحويل الصيغ |

> يمكن تثبيت yt-dlp وFFmpeg مباشرة من **الإعدادات ← المحرّكات والمكتبات ← تثبيت الناقص**. تُثبّت الأدوات في `<userData>/bin` وتُستخدم قبل الأدوات المثبتة على النظام. يبقى التثبيت اليدوي متاحًا كبديل.

### تثبيت الأدوات

**Linux (Debian/Ubuntu):**

```bash
sudo apt update
sudo apt install -y ffmpeg
sudo apt install -y yt-dlp
# أو أحدث نسخة:
python3 -m pip install -U yt-dlp
```

**macOS:**

```bash
brew install yt-dlp ffmpeg
```

**Windows:**

```powershell
winget install yt-dlp.yt-dlp
winget install Gyan.FFmpeg
```

بديل: ضع `yt-dlp` و`ffmpeg` داخل مجلد `bin/` في المشروع (راجع `bin/README.md`). يمكن أيضًا تحديد مسار مخصص عبر متغيّري البيئة `YT_DLP_PATH` و`FFMPEG_PATH`.

## طريقة الاستخدام

1. افتح تبويب **التحميل**.
2. الصق رابط الفيديو في الحقل، ثم اضغط **تحليل الرابط**.
3. اختر **فيديو** أو **صوت فقط**، ثم حدّد الجودة أو الصيغة.
4. فعّل خيارات إضافية عند الحاجة: دمج البيانات والغلاف، تحميل الترجمة، أو تحميل قائمة التشغيل كاملة.
5. اختر **مصدر الكوكيز** إذا كان الموقع يتطلب تسجيل دخول (المتصفح المدمج هو الأسهل).
6. اضغط **تحميل الآن**، وتابع التقدم في قائمة التحميل. يمكنك إلغاء أي عنصر أو فتح ملفه بعد اكتماله.

للاستخدام عبر المتصفح:

1. افتح تبويب **المتصفح** واكتب العنوان أو عبارة البحث.
2. سجّل الدخول إلى الموقع إن لزم الأمر.
3. اضغط **تحميل الصفحة** لتحليل الصفحة الحالية.
4. أو انقر بزر الفأرة الأيمن على أي رابط، ثم اختر **تحميل بواسطة Honk** من قائمة السياق.
5. يمكنك إفلات رابط في أي مكان داخل نافذة التطبيق لبدء تحليله وتحميله تلقائيًا.

اختصارات سريعة:

- `Ctrl+L`: الانتقال إلى شريط عنوان المتصفح.
- `Ctrl+1` / `Ctrl+2` / `Ctrl+3` / `Ctrl+4`: التنقل بين التحميل والمتصفح والإضافات والإعدادات.
- `F12`: أدوات المطور.
- `Esc`: إغلاق شريط الرابط المحدد.

## كيف يعمل التحميل؟

1. الواجهة ترسل الرابط إلى النواة عبر `ipcMain.handle('yt:info')`.
2. `downloader.js` يشغّل:

```bash
yt-dlp --dump-single-json --no-playlist -- <url>
```

3. تُعاد بيانات الفيديو (العنوان، الصورة، المدة، الجودات) إلى الواجهة.
4. عند الضغط على «تحميل الآن»، يشغّل التطبيق yt-dlp مع:

```bash
# فيديو
yt-dlp -f "bv*[height<=1080]+ba/b[height<=1080]" --merge-output-format mp4 -o "<folder>/%(title).150s [%(id)s].%(ext)s" -- <url>

# صوت
yt-dlp -f "ba/b" -x --audio-format mp3 --audio-quality 0 -o "<folder>/%(title).150s [%(id)s].%(ext)s" -- <url>
```

5. يقرأ التطبيق مخرجات yt-dlp سطرًا بسطر لاستخراج نسبة التقدّم والسرعة والوقت المتبقي، ثم يرسلها إلى الواجهة عبر IPC.
6. عند الحاجة، يستخدم FFmpeg لدمج مسار الفيديو مع الصوت أو لتحويل الصيغة.

### نقاط مهمة في الأمان

- `contextIsolation: true` و`nodeIntegration: false` في نافذة الواجهة.
- لا تُعرّض الواجهة إلا دوال IPC محددة في `preload.js`.
- يتم تمرير `--` قبل الرابط لمنع حقن خيارات إضافية في yt-dlp.
- يُفحص الرابط بـ `new URL()` ويُسمح فقط بـ `http` و`https`.
- لا يتم تحميل أي سكربت من الإنترنت داخل واجهة التطبيق (CSP صارم).

## كيف أضفت المتصفح؟

المتصفح ليس مشروعًا منفصلًا، بل **webview** داخل نافذة Electron. الخطوات:

### 1. تفعيل الوسم

في `src/main/main.js` أثناء إنشاء النافذة:

```js
webPreferences: {
  preload: path.join(__dirname, 'preload.js'),
  contextIsolation: true,
  nodeIntegration: false,
  webviewTag: true
}
```

### 2. إضافة العنصر في الواجهة

في `src/renderer/index.html`:

```html
<webview
  id="browser-view"
  src="https://www.youtube.com"
  partition="persist:honk-browser"
  allowpopups>
</webview>
```

- `partition="persist:honk-browser"` يحفظ الكوكيز وجلسة تسجيل الدخول بين التشغيلات.
- `allowpopups` يسمح للإشارات بفتح نوافذ، لكن النواة تعترضها وتحوّلها إلى تنقّل داخلي.

### 3. التحكم في التنقل

في `src/renderer/app.js`:

```js
browserView.loadURL(url);
browserView.goBack();
browserView.goForward();
browserView.reload();
browserView.getURL();
```

ويتم تحديث شريط العنوان عبر أحداث `did-navigate` و`did-navigate-in-page` و`dom-ready`.

### 4. اعتراض النوافذ المنبثقة والروابط

في `src/main/main.js`:

```js
app.on('web-contents-created', (_event, contents) => {
  if (contents.getType() !== 'webview') return;

  contents.setWindowOpenHandler(({ url }) => {
    sendToWindow('browser:open-url', url);
    return { action: 'deny' };
  });

  contents.on('context-menu', (_menuEvent, params) => {
    if (params.linkURL) {
      sendToWindow('browser:context-link', {
        url: params.linkURL,
        text: params.linkText || ''
      });
    }
  });
});
```

ثم تعرض الواجهة شريطًا صغيرًا لتحميل الرابط المحدد أو فتحه.

### 5. تقوية الجلسة

- تعيين User-Agent يشبه Chrome لتجنّب حجب المواقع.
- رفض طلبات الأذونات غير الضرورية (الكاميرا، الموقع الجغرافي، الإشعارات...).
- منع تحميل `preload` داخل webview وتعطيل Node فيه عبر `will-attach-webview`.

### 6. استخدام الكوكيز في التحميل

يمكن اختيار مصدر الكوكيز من قائمة في تبويب التحميل أو الإعدادات:

| المصدر | ما يفعله التطبيق |
|---|---|
| بدون كوكيز | لا يمرّر أي كوكيز. |
| المتصفح المدمج | يقرأ جلسة `persist:honk-browser` عبر `src/main/cookies.js` ويكتبها بصيغة Netscape ثم يمرّرها بـ`--cookies`. |
| Chrome / Chromium / Firefox / Brave / Edge / Opera / Vivaldi / Safari | يمرّر `--cookies-from-browser <name>` مباشرة إلى yt-dlp. |

هكذا تستطيع تحميل محتوى يتطلب تسجيل دخول من يوتيوب أو إنستغرام أو فيسبوك أو تيك توك وغيرها. إن لم تنجح قراءة كوكيز المتصفح الخارجي، استخدم المتصفح المدمج وسجّل الدخول داخله.

## إضافات المتصفح

المتصفح المدمج يستخدم جلسة Electron الدائمة `persist:honk-browser` ويدعم تحميل إضافات Chrome (Manifest V2/V3) عبر `src/main/extensions.js`.

1. افتح تبويب **الإضافات**.
2. اختر أحد الخيارات:
   - **إضافة من مجلد**: حدّد مجلدًا يحتوي `manifest.json`.
   - **تثبيت .crx / .zip**: اختر ملف إضافة مضغوطًا (يُستخرج تلقائيًا بأمان).
   - **تثبيت الإضافة المدمجة**: يثبّت **Honk Media Grabber**.
3. بعد التثبيت، أعد تحميل صفحة المتصفح أو أعد تشغيل التطبيق إن لزم.

الإضافات تُثبّت في `<userData>/extensions` وتُحمّل تلقائيًا عند بدء التشغيل. يمكن فتح المجلد مباشرة من زر **فتح مجلد الإضافات**، ومراجعة أخطاء التحميل داخل قائمة الإضافات.

### Honk Media Grabber

إضافة MV3 مدمجة (`extensions/honk-media-grabber`) تُضيف زرًا عائمًا في صفحات الويب، وتعمل أيضًا من أيقونة الإضافة في شريط المتصفح:

- تكتشف روابط `<video>` و`<audio>` و`<source>` وروابط `.mp4` و`.m3u8` و`.mp3` وغيرها، إضافة إلى وسوم `og:video` و`og:audio` وبيانات JSON-LD.
- تراقب طلبات الشبكة عبر `webRequest` لالتقاط روابط البث التي لا تظهر في DOM.
- تعرض قائمة قابلة للتصفية (الكل / فيديو / صوت / بث) مع عدد الروابط المكتشفة.
- تتيح نسخ رابط واحد أو نسخ كل الروابط، أو **إرسال الصفحة/الرابط مباشرة إلى التطبيق**.
- تفتح التطبيق عبر `honk://open` وتُظهر حالة اتصال الجسر المحلي، مع نسخ احتياطي إلى الحافظة عند عدم تشغيل التطبيق.
- اختصار لوحة الإضافة: `Alt+Shift+H`.

**جسر الإضافة:** يعمل على `127.0.0.1` فقط (المنفذ الافتراضي `47821` مع محاولات حتى `47825`)، ولا يستقبل إلا روابط `http/https`. يمكن تعطيله أو تغيير سلوك التحميل التلقائي من **الإعدادات ← جسر إضافة المتصفح**، واختبار الاتصال أو إعادة تشغيله من هناك.

**ملاحظة:** بعض إضافات Chrome تعتمد على واجهات غير مدعومة في Electron (مثل `chrome.identity` أو متجر Chrome)، لذلك قد لا تعمل جميع الإضافات بشكل كامل. الإضافات التي تعمل عبر content scripts تعمل عادةً بسلاسة.

## تحديث yt-dlp

المواقع تتغيّر باستمرار، لذا حدّث yt-dlp عند فشل التحليل:

- من التطبيق: **الإعدادات ← المحرّكات والمكتبات ← تحديث yt-dlp**.
- من الطرفية:

```bash
yt-dlp -U
# أو
python3 -m pip install -U yt-dlp
```

ترتيب البحث عن الأدوات: متغيّر البيئة (`YT_DLP_PATH` / `FFMPEG_PATH`) ← `<userData>/bin` ← `bin/` داخل المشروع ← `PATH`. لذلك فإن التثبيت من داخل التطبيق لا يغيّر أدوات النظام، لكنه يتقدّم عليها في البحث.

## كيف تضيف دعم موقع جديد؟

المحرّك هو yt-dlp، ويدعم أكثر من ألف موقع عبر **Extractors**. عادةً لا تحتاج إلى كتابة كود إضافي:

1. **تأكد من التحديث أولًا:**

```bash
yt-dlp -U
# أو
python3 -m pip install -U yt-dlp
```

2. **جرّب الموقع مباشرة:**

```bash
yt-dlp --simulate --dump-single-json "https://example.com/video"
```

3. **إن كان الموقع مدعومًا:** سيظهر في التطبيق تلقائيًا.

4. **إن لم يكن مدعومًا:** قد يعمل **Generic Extractor** تلقائيًا لاكتشاف ملفات `mp4` أو `m3u8` داخل الصفحة. جرّب رابط الصفحة نفسه أو رابط الملف المباشر.

5. **إن كان الموقع يتطلب تسجيل دخول:** سجّل الدخول في تبويب المتصفح ثم اختر **المتصفح المدمج** كمصدر للكوكيز.

6. **إن كان الموقع جديدًا تمامًا:** أضف Extractor لـ yt-dlp نفسه (عادةً ملف Python داخل `yt_dlp/extractor/`)، ثم أعد تثبيت yt-dlp. التطبيق سيستخدمه فورًا دون تعديل.

### إضافة موقع لا يدعمه yt-dlp

- إذا كان الموقع يعرض رابطًا مباشرًا (`https://site.com/file.mp4` أو `.m3u8`)، ضعه كما هو في حقل الرابط.
- إذا كان الرابط محميًا بتوقيع مؤقت، استخدم تبويب المتصفح لتشغيل الفيديو ثم زر «تحميل الصفحة».
- يمكن لاحقًا إضافة Extractor مخصص عبر خيار `--load-info-json` أو كتابة إضافة yt-dlp، لكن ذلك خارج نطاق هذا التطبيق.

## استكشاف الأخطاء

| المشكلة | الحل |
|---|---|
| «لم يتم العثور على yt-dlp» | اضغط **الإعدادات ← تثبيت الناقص**، أو ثبّته عبر الحزمة أو ضعه في `bin/`، أو اضبط `YT_DLP_PATH`. |
| «تحويل الصوت يتطلب FFmpeg» | اضغط **الإعدادات ← تثبيت الناقص**، أو ثبّت FFmpeg واضبط `FFMPEG_PATH`. |
| فشل التثبيت التلقائي | تحقّق من اتصال الإنترنت، ثم أعد المحاولة أو ثبّت الأدوات يدويًا من قسم المتطلبات. |
| الإضافة لا تستطيع الإرسال للتطبيق | شغّل التطبيق أولًا وتأكّد من أن الجسر «يعمل» في الإعدادات، ثم اضغط **اختبار**. |
| فشل تحليل الرابط | حدّث yt-dlp من الإعدادات أو `bin/yt-dlp -U`، وتأكد أن الرابط يعمل في المتصفح. |
| يوتيوب يعرض «The page needs to be reloaded» | إصدار yt-dlp قديم؛ استخدم زر **تحديث yt-dlp**. |
| الموقع يطلب تسجيل دخول | سجّل الدخول في تبويب المتصفح واختر **المتصفح المدمج** كمصدر للكوكيز، أو اختر متصفحك. |
| فيديو بلا صوت بعد الدمج | تأكد من تثبيت FFmpeg وأنه ظاهر كـ«متوفر» في الإعدادات. |
| إضافة لا تعمل | جرّب **إعادة تحميل** من تبويب الإضافات، وأعد تحميل الصفحة. بعض إضافات Chrome غير مدعومة في Electron. |
| المتصفح لا يفتح موقعًا | بعض المواقع تمنع المتصفحات المدمجة؛ جرّب رابط الفيديو المباشر. |
| الشاشة بيضاء | شغّل `npm run check` ثم `npm start` وراجع وحدة التحكم بـ`F12`. |

سجلات إضافية أثناء التطوير:

```bash
ELECTRON_ENABLE_LOGGING=1 npm start
```

## التغليف

```bash
npm run dist:linux
npm run dist:win
npm run dist:mac
```

الناتج في مجلد `dist/`. لتضمين الأدوات داخل الحزمة، ضعها في `bin/` قبل البناء. الإضافة المدمجة تُنسخ من `extensions/` عبر `extraResources`. إعدادات `electron-builder` موجودة في `package.json`.

## ملاحظة قانونية

هذا التطبيق أداة تقنية عامة. تأكد من امتلاكك حقوق تحميل المحتوى ومن التزامك بشروط استخدام المواقع وقوانين حقوق النشر في بلدك. لا تستخدمه لتحميل محتوى محمي دون إذن.

## التصميم

الواجهة الحالية مبنية على هوية Honk:

- خلفية فاتحة أو داكنة حسب السمة، مع تدرّجات زرقاء ولمسات صفراء خفيفة بدل تعبئة الشاشة بالكامل.
- Honk Blue `#008fff` للعناصر الأساسية، وSignal Yellow `#ffe400` للتمييز والتفاصيل.
- ألواح بحواف `18px` وظلال ناعمة، وأزرار واضحة بحالات hover وfocus.
- تخطيط متجاوب من عمودين إلى عمود واحد، وشريط علوي بتبويبات وأربع شاشات: التحميل، المتصفح، الإضافات، الإعدادات.
- سمة داكنة كاملة، مع دعم `prefers-color-scheme` عند اختيار «حسب النظام».
- خطوط عربية سميكة للعناوين مع بدائل نظامية، واتجاه RTL كامل.
