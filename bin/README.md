# مجلد الأدوات (bin)

ضع هنا ملفات `yt-dlp` و`ffmpeg` التنفيذية إذا أردت أن يعمل التطبيق دون الاعتماد على الأدوات المثبتة في النظام.

- Linux / macOS: ضع الملفات باسم `yt-dlp` و`ffmpeg` ثم اجعلها قابلة للتنفيذ: `chmod +x yt-dlp ffmpeg`.
- Windows: ضع `yt-dlp.exe` و`ffmpeg.exe`.

أثناء التغليف (electron-builder) يُنسخ هذا المجلد إلى موارد التطبيق تلقائيًا.

ترتيب البحث عن الأدوات:

1. متغيّر البيئة `YT_DLP_PATH` أو `FFMPEG_PATH`.
2. هذا المجلد `bin/`.
3. مجلدات PATH في النظام.
